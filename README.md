# desafio-mutant
Desafio mutant: 4 cenarios simples com automações em Playwright + Typescript
 
 O que é o desafio: 
 
"Cenário 1 — Login com sucesso.
Acesse o site https://www.saucedemo.com/
Realize login com usuário válido:
Usuário: standard_user
Senha: secret_sauce
Valide que o login foi realizado com sucesso.
Valide que a página de produtos foi exibida.

Cenário 2 — Login inválido.
Acesse o site.
Tente realizar login com credenciais inválidas.
Valide que a mensagem de erro foi exibida.

Cenário 3 — Adição de produto ao carrinho.
Faça login com usuário válido.
Adicione um produto ao carrinho.
Acesse o carrinho.
Valide que o item adicionado está listado no carrinho.

Cenário 4 — Logout.
Faça login com usuário válido.
Realize logout.
Valide que o usuário retornou para a tela de login.


Requisitos técnicos
Projeto em Python ou outra linguagem de programação
Automação desenvolvida em Playwright ou Robot Framework
Arquivo README.md contendo:
como instalar dependências
como executar os testes
breve descrição da estrutura do projeto
Casos de teste automatizados funcionando

Evidências de execução, podendo ser:
relatório
prints
ou vídeo curto"
